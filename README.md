<h1 align="center">Detaggarr</h1>

<p align="center">Bulk-remove tags from your Sonarr series and Radarr movies.</p>

---

Detaggarr is a small Windows desktop app that connects to Sonarr or Radarr, shows every tag
and how many items use it, and removes the tags you choose from as many series or movies as you
like in one go.

## Features

- Connects to **Sonarr** (v3/v4) or **Radarr** (v3+) with a URL and API key
- Lists all tags with a usage count
- Pick tags from the list, or type them comma-separated (e.g. `anime, kids`)
- Preview every affected series/movie and untick any you want to leave alone
- Removes tags in a single bulk request via the Sonarr/Radarr editor API
- Optionally deletes the tag from the server once nothing uses it any more
- Remembers your URL and API key for each service
- Single `.exe`, no install or Python required

## Usage

1. Download `Detaggarr.exe` from the [Releases](../../releases) page (or build it yourself below).
2. Choose **Sonarr** or **Radarr**, enter the URL (e.g. `http://localhost:8989`) and your API key
   (found in *Settings → General*), then click **Connect**.
3. Select the tags to remove. Every series/movie that has them appears on the right.
4. Deselect anything you want to keep, then click **Remove**.

Settings are saved to `%APPDATA%\Detaggarr\config.json`. The API key is stored in plain text there.

> Windows SmartScreen may warn on first launch because the exe is unsigned. Choose
> *More info → Run anyway*.

## Building from source

Requires Python 3.10+ (with tkinter, included in the standard Windows installer).

```bash
python -m venv .venv
.venv\Scripts\python -m pip install pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --onefile --windowed --name Detaggarr --icon assets\detaggarr.ico --add-data "assets\detaggarr.ico;assets" detaggarr.py
```

The exe is written to `dist\Detaggarr.exe`. To run without building: `python detaggarr.py`.

The logo is generated by `assets/make_logo.py` (needs Pillow).
